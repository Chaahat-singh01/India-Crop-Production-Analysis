# 🌾 India Crop Production Analysis Dashboard

## 📌 Project Overview

This Power BI dashboard analyzes crop production across India using state-wise, district-wise and crop-wise agricultural data.

The dashboard helps identify:

- Top producing crops
- State-wise production trends
- Seasonal crop yield distribution
- Production rankings over time
- Agricultural performance insights

---

## 🛠 Tools Used

- Power BI
- Power Query
- DAX
  

---

## 📊 Key KPIs

- Total Production
- Total Area
- Total Districts
- Total Crops
- Average Yield

---

## 📈 Dashboard Features

### Summary Page

- KPI Cards
- State-wise Production Map
- Crop Distribution Analysis
- Production Trend Analysis
- Interactive Filters

### Overview Page

- Treemap Analysis
- Seasonal Yield Breakdown
- Crop Ranking by Year
- Dynamic Slicers
